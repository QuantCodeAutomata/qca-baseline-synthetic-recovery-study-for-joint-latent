# QCA Baseline Synthetic Recovery Study for Joint Latent-State EM in Credit Risk

## Overview

This project contains two synthetic experiments for studying latent-state estimation in credit risk models.

**Experiment 1 — Joint EM Recovery:** Validates that the joint EM algorithm correctly recovers the true parameters of a 4-component Gaussian mixture model with Bernoulli default indicators. Starting from random initialisation, the estimator is evaluated on parameter recovery accuracy (means, mixing weights, and default probabilities).

**Experiment 2 — Product-of-Marginals Approximation:** Analyses the approximation error introduced by replacing the true joint posterior over latent states with a product-of-marginals factorisation. The experiment sweeps across the estimated parameters recovered in Experiment 1 and reports divergence metrics between the exact and approximate posteriors.

## Repository Structure

```
data/       Raw and synthetic input data
src/        Core library modules (DGP, EM estimator, posteriors, metrics, etc.)
exp/        Experiment scripts (exp1_recovery.py, exp2_product_marginals.py)
tests/      Unit and integration tests
results/    Output CSV files and PNG plots generated by experiments
```

## Experiments

| Script | Description |
|--------|-------------|
| `exp/exp1_recovery.py` | Joint EM parameter recovery on a 4-component Gaussian mixture with Bernoulli defaults |
| `exp/exp2_product_marginals.py` | Product-of-marginals approximation quality analysis using recovered parameters |
